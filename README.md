# HvH Fabric Mod (Minecraft 1.21.11)

Клиентский Fabric-мод, который для локального игрока возвращает полный прогресс кулдауна атаки. На серверах поведение может ограничиваться серверной логикой/античитом.

## Сборка через GitHub Actions
1. Распакуйте архив и загрузите содержимое проекта в корень репозитория.
2. Убедитесь, что workflow лежит по пути `.github/workflows/build.yml`.
3. Сделайте push в ветку `main` или запустите workflow вручную через вкладку Actions.
4. В успешном запуске откройте Artifacts и скачайте `HvH-Mod-JAR`.
5. Извлеките `.jar` из скачанного ZIP и поместите его в папку `mods` клиента Minecraft с Fabric Loader для Minecraft 1.21.11.

## Требования
- Minecraft Java Edition 1.21.11
- Java 21
- Fabric Loader и Fabric API для 1.21.11

## Важно
Это исходный проект для сборки, а не уже скомпилированный `.jar`. GitHub Actions создаст JAR при успешной сборке.
